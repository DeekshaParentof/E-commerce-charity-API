# Charity Shop: Frontend

The React + Vite + Tailwind client for the Charity Shop API.

```bash
npm install
cp .env.example .env   # set VITE_API_URL to your API, e.g. http://localhost:8080/api/v1
npm run dev
```

See the [root README](../README.md) for full setup, environment variables, the API reference and deployment steps.
